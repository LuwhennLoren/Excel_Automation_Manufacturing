# Manufacturing Data Cleanup with Power Query

## Overview
An Excel-based data cleaning project using Power Query to automate the cleanup of messy manufacturing data — from inconsistent formatting to duplicate records — turning it into a clean, analysis-ready dataset.

## How to View This Project
This is an Excel (.xlsx) file with Power Query applied steps. To view it:
1. Download the `.xlsx` file from this repository
2. Open it in Microsoft Excel
3. Go to Data → Queries & Connections to see the applied Power Query steps

## Tech Stack
- Microsoft Excel
- Power Query

## What I Did
- Identified common data quality issues in raw manufacturing data (duplicates, inconsistent formatting, incorrect data types)
- Built a repeatable Power Query workflow to clean the data automatically
- Applied basic statistical measures to explore patterns in the cleaned dataset

## Key Steps
1. Imported the raw, messy dataset into Power Query
2. Removed duplicate records
3. Standardized text formatting and corrected data types
4. Loaded the cleaned data back into Excel for analysis

## What I Learned
This project helped me practice building reusable data cleaning workflows in Excel using Power Query, reducing the need for manual, repetitive cleanup. It also strengthened my understanding of basic statistical concepts for interpreting data.
